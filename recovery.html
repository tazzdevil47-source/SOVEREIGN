⚜ Sovereign — Emergency Recovery

Exporting does not change your saved data. Importing will overwrite matching keys only after explicit confirmation. It runs without Sovereign's React application. Use it on the same Vercel domain and in the same browser/profile as your game.

If you see zero keys, do not clear storage or assume your records are lost. You may be on a different domain, browser profile, or storage context.

2. Export everything first

Download a raw copy of every localStorage key, including values that aren't valid JSON. This is the safest first backup.

Backup may contain sensitive personal information and the Imperial Seal hash. Keep it private. Do not upload it to GitHub.

3. Inspect what was found

Only key names, sizes and JSON validity are shown here. The actual records are not displayed.

4. Import / Restore a saved backup

Select the sovereign-raw-recovery-....json file exported by this page. The import preserves all other keys, but overwrites keys included in the backup. Deploy the repaired Sovereign app before restoring.

5. Next steps

After a successful import, reopen Sovereign on the same domain and browser. Check your records before entering new data. Do not clear browser storage or reset the Imperial Seal.
